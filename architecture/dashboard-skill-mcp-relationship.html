Copilot Studio architecture

Dashboard skill decides. MCP app renders.

The skill is the orchestration contract that tells the agent when to build a dashboard and how to shape its data. The MCP app is the runtime renderer that turns that structured payload into supported embedded HTML.

Step 1 · Input

User requests a dashboard

The process starts with a natural-language request. The requested period and desired output become the agent's working context.

  • Captures the number of days
  • Identifies dashboard intent
  • Preserves product or source scope
Key relationship request → agent orchestration
Skill = behavior

It tells the model when to render, which records to keep, how to calculate metrics, and which fields become filters.

MCP = supported UI runtime

It exposes the tool and HTML resource, validates the payload, and returns both the interactive output and a text fallback.

Together = reliable embedded HTML

The skill creates a predictable contract; MCP turns that contract into a secure, sandboxed, interactive experience.
